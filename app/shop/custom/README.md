# Classmates' products (10 slots)

Fill in `products.csv` and drop a photo per product into this folder. Nothing else to change.

| Column | What to write | Example |
| --- | --- | --- |
| id | leave as it is (c01 … c16; must not clash with the shop's p011–p100) | c01 |
| name | product name | Lukas's Emergency Cepelinas |
| category | leave "Classmates" (or Kitchen, Tech, Beauty, Home, Sports, Pets, Office) | Classmates |
| price | price in euros, a number | 49 |
| description | one funny sentence | Reheats itself during exams. |
| photo | file name of the photo in this folder | p001.jpg |

Rows with an empty name are hidden in the shop. Mix the prices: under €100, €100–250 and over €250 are three
different "price bands" for the model, so a spread makes the demo more interesting.
Photos can be any size; the shop crops them to a square.
